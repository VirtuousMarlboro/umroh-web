# Al-Safwa Travel Website

Project ini adalah website landing page modern untuk biro perjalanan Umroh "Al-Safwa Travel". Website ini dirancang untuk menampilkan informasi paket travel, keunggulan layanan, testimoni, dan memfasilitasi pendaftaran calon jamaah secara online.

## 🌟 Fitur Utama

*   **Desain Responsif**: Tampilan yang optimal di berbagai perangkat (Desktop, Tablet, Mobile).
*   **Navigasi Modern**: Menu navigasi yang sticky dengan smooth scrolling dan mobile-friendly (hamburger menu).
*   **Animasi Interaktif**:
    *   Scroll animations (fade-in, slide-up) saat menggulir halaman.
    *   Counter animasi untuk statistik (jumlah jamaah, pengalaman, rating).
*   **Pilihan Paket**: Bagian khusus yang menampilkan detail paket (Regular, Premium, VIP) dengan harga dan fitur.
*   **Formulir Pendaftaran**:
    *   Validasi input real-time (Nama, Email, WhatsApp).
    *   Notifikasi error (Toast messages) yang user-friendly.
    *   Modal konfirmasi sukses setelah pengiriman data.
*   **Galeri & Testimoni**: Menampilkan dokumentasi perjalanan dan ulasan dari jamaah sebelumnya.

## 🛠️ Teknologi yang Digunakan

*   **HTML5**: Struktur semantik halaman.
*   **CSS3**: Styling modern, flexbox/grid layout, dan animasi CSS.
*   **JavaScript (Vanilla)**: Logika interaktivitas, validasi form, dan manajemen DOM tanpa framework tambahan.
*   **Google Fonts**: Menggunakan font 'Poppins' dan 'Inter' untuk tipografi yang elegan.

## 🚀 Cara Menjalankan

Project ini adalah website statis, sehingga Anda tidak memerlukan server backend khusus untuk menjalankannya.

1.  **Clone atau Download** repository ini.
2.  Buka file `index.html` langsung di browser web Anda (Chrome, Firefox, Edge, Safari, dll).
    *   Atau gunakan ekstensi "Live Server" di VS Code untuk pengalaman development yang lebih baik.

## 📂 Struktur File

*   `index.html`: File utama struktur halaman.
*   `styles.css`: File stylesheet untuk seluruh tampilan dan layout.
*   `script.js`: File logika JavaScript untuk interaksi dan animasi.
*   `images/`: Folder untuk aset gambar (pastikan file gambar tersedia di folder ini).

## 📝 Catatan Pengembangan

*   Bagian formulir saat ini hanya melakukan validasi di sisi klien dan menampilkan simulasi sukses (belum terhubung ke database backend).
*   Pastikan folder `images` terisi dengan file gambar yang sesuai (gallery-1.jpg, dst) agar tampilan gambar tidak rusak.
